How it works

No servers, no signups, no bills. Everything happens in your browser.

1

You paste a repo URL

Blueprint downloads the public repo archive and distills it: file tree, README, manifests, and entry-point files — trimmed to a tight evidence budget.

2

Gemini draws the spec

Your free Gemini key sends that evidence to the model with strict authoring rules. It returns a typed diagram spec — components, edges, and nothing invented.

3

Verified, then rendered

The spec is validated against the real Archify JSON schemas before a single pixel is drawn. Invalid output is rejected with a clear error, never rendered.

4

Explore & export

Pan, zoom, click any node for details, toggle dark/light, refine in chat, export PNG/SVG/JSON. Diagram format inspired by Archify (MIT).
